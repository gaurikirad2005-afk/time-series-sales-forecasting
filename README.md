# Sales Forecasting & Business Analytics

## Project Overview

This project focuses on analyzing historical sales data and forecasting future sales using Python-based data analysis and machine learning techniques.

The project follows an end-to-end workflow from data exploration and feature engineering to sales forecasting and business visualization.

## Objectives

- Analyze historical sales trends
- Perform exploratory data analysis
- Prepare and transform sales data
- Create features for forecasting
- Train a sales forecasting model
- Generate future sales predictions
- Prepare forecast data for business visualization
- Develop an interactive Tableau dashboard

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook
- Tableau
- Git & GitHub
